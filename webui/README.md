# VisualModel Dataset Studio (WebUI)

VisualModel の `datasets/` ディレクトリ配下にある画像＆プロンプトデータセットを快適に閲覧・編集・分析するためのモダンWebUIツールです。

---

## 🌟 主な機能

1. **データセット閲覧・管理**
   - `datasets/` 配下のサブフォルダ（例: `test` など）を自動検出・瞬時に切り替え
   - グリッドギャラリー表示（サムネイルサイズ変更スライダー付き）
   - 解像度、アスペクト比、ファイル容量、テンソル生成有無バッジの表示
   - ファイル名・文字数・更新日時・解像度による並び替え（ソート）
   - プロンプト全文検索 & ファイル名インクリメンタル検索

2. **画像の高精細プレビュー & プロンプト編集**
   - 選択中画像の高解像度プレビュー & 全画面ズームモーダル
   - プロンプトの直接編集 & ワンクリック保存（`Ctrl + S` 対応）
   - 同名の個別 `.txt` ファイル、および `captions.json` がある場合は両方を自動同期更新
   - 変更検知（保存済み / 未保存ステータスバッジ）
   - 元に戻す（リセット）、クリップボードコピー

3. **リアルタイム文字数・単語数カウンター**
   - **文字数 (スペース込み)**
   - **文字数 (空白除外)**
   - **単語数 (形態素・フレーズ推定)**
   - **行数**
   - **日本語BERTトークン数目安**（最大256トークンに対する上限警告表示付き）

4. **データセット全体の単語出現頻度・統計分析**
   - データセット全体でどの単語が何回使われているかを集計
   - **頻度ランキングテーブル**: 順位、単語、出現回数、出現画像数、出現割合プログレスバー
   - **タグ / ワードクラウド表示**: 頻度に応じたフォントサイズとカラーのビジュアル表示
   - **単語クリックで即座に絞り込み**: 単語をクリックすると、その単語を含む画像一覧のみをギャラリーに即時フィルタ表示
   - 助詞・ストップワード除外フィルタ、最小文字数絞り込み、単語検索
   - 統計データのCSVエクスポート機能

5. **便利な追加機能**
   - **一括単語置換**: データセット全体のプロンプトから特定単語を一括置換（置換前プレビュー確認付き）
   - **テンソル生成 (prepare_text.py)**: WebUI上からワンクリックで特徴量テンソル（.pt）をバックグラウンド再生成し、ターミナルログをリアルタイム監視

## 🚀 起動方法

### 方法 1: ルート直下のバッチファイルを実行（推奨）
プロジェクトのルート直下にある `run_webui.bat` をダブルクリック（またはコマンドプロンプトで実行）してください。
自動的にサーバーが立ち上がり、ブラウザで `http://127.0.0.1:7860/` が開きます。

```bat
.\run_webui.bat
```

### 方法 2: Pythonコマンドで起動
```bash
python webui/server.py
```

※ オプション:
- `--port 8000`: ポート番号を指定（デフォルト: 7860）
- `--no-browser`: 起動時にブラウザを自動で開かない

## ⌨️ キーボードショートカット

| ショートカット | 機能 |
| :--- | :--- |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | プロンプトを即時保存 |
| <kbd>Ctrl</kbd> + <kbd>←</kbd> / <kbd>→</kbd> | 前 / 次の画像へ切り替え |
| <kbd>←</kbd> / <kbd>→</kbd> または <kbd>k</kbd> / <kbd>j</kbd> | （テキストエリア非フォーカス時）前 / 次の画像へ移動 |
| <kbd>Esc</kbd> | 各種モーダル（単語統計、一括置換、テンソル生成、画像ズーム）を閉じる |
